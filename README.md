# Za3bolaDB

A high-performance, custom-built NoSQL Document Database.

## Features (Planned)
- In-memory performance with disk persistence.
- TCP Server for remote access.
- Lightweight custom protocol.
- Document-based storage (JSON).

## Architecture
- **Server:** TCP-based multi-threaded server.
- **Engine:** Key-value store with JSON support.
- **Client:** CLI-based interaction.
